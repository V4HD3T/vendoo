# Vendoo Backend

## Setup

```bash
npm install
cp .env.example .env      # fill in .env (DB credentials, JWT_SECRET)
npm run migrate           # creates the tables
npm run seed               # adds 54 products + demo users
npm run dev                 # http://localhost:3000
```
